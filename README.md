# Cartographer-V4-MOUNT-For-K1.
Cartographer V4 implementation into K1, using SAF firmware
<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/629fe0a2-9fe2-49cd-b66d-602f61a5d5bf" />

BOM:
2x M3x12mm Socket head Cap Screws
1x Cartographer V4 probe

6/6/2026 Start of project
My goal is to implement the cartographer V4 into the side of the Creality k1 printhead, with a combination of kalico, klipper, and SAF Firmware.
<img width="910" height="685" alt="image" src="https://github.com/user-attachments/assets/d6b8f736-16fb-47bf-a68d-28f53a9d2235" />
Idea and concept is based on the V3 implementation, from OG SAF Firmware. I will be developing a custom mount for this V4 module, which will screw directly onto the k1 printhead. Using a Cartographer V4, I will be able to scan and probe the mesh quicker than ever.

6/8/2026
Using inspiration from Purcell, mount has been completed!
Made the mount for the K1 Printer, ready for testing. Mount will be used to mount the cartographer V4 onto the K1 printhead, using 2x M3x12mm machine socket head cap screws.
